### 💡 How to Add / Replace Your Correct Logos:
1. **File Formats Supported**: `.svg`, `.png`, `.jpg`, `.webp`.
2. **Transparent Backgrounds**: Transparent PNGs or clean vector SVGs look best on the obsidian glass cards.
3. **Automatic Fallback Engine**: If you drop in `isro.png`, the system will automatically detect and load `isro.png` even if `isro.svg` is absent!
4. **Recommended Resolution**: Height ~100–300px (or vector). The cards automatically scale and contain the logos neatly.
